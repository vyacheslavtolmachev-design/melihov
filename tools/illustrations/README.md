# Ботанические иллюстрации сортов

Пилотный генератор графики для каталога: тонкий золотой контур на тёмно-зелёном
фоне, тот же язык, что у логотипа и иконок культур (`docs/GRAPHICS.md`, раздел 3).
Решение принято вместо фотографий: у нас нет ни собственной съёмки по сортам,
ни доступа к генерации/лицензированию изображений с уверенной привязкой к
конкретному сорту, а не просто к культуре.

## Что это

Каждый сорт — параметрический SVG (`draw.py` — примитивы: кривые, лист, сцена,
маски для перекрытий; `fruits.py` — рисовальщики по культурам: яблоня, груша,
черешня/вишня, слива, смородина; `varieties.py` — какие сорта нарисованы и с
какими параметрами формы). `generate.py` собирает SVG и рендерит его в WebP
800×1000 через `sharp` внутри контейнера `melihov-frontend` (у него есть libvips
с librsvg; ImageMagick свой SVG-движок градиенты и `feTurbulence` не тянет).

Раскладка кадра рассчитана на оба кропа сайта: карточка каталога (`aspect-4/5`
— полотно 800×1000 совпадает с этим соотношением один в один) и страница сорта
(`aspect-4/3` — видна средняя полоса `y 200…800`). Плод и подпись держатся
внутри этой безопасной зоны.

## Команды

```bash
python3 generate.py                        # все сорта из varieties.py
python3 generate.py apple-golden-delishes  # один сорт
python3 generate.py --svg-only             # без докера, только SVG
```

## Как добавить сорт

1. Если культуры ещё нет — завести рисовальщик в `fruits.py` (профиль плода как
   правая половина контура сверху вниз, см. docstring `outline()`).
2. Добавить запись в `VARIETIES` (`varieties.py`) со слагом из
   `wordpress/catalog/varieties.tsv`, названием, alt-текстом и параметрами формы.
3. Сгенерировать и посмотреть глазами — `out/{slug}.webp`.
4. Залить как featured image: `wordpress/import-illustrations.sh` (шаблон на
   пять пилотных сортов — скопировать файл в `wordpress/catalog/illustrations/`
   и добавить вызов `import_one`).

## Ограничения пилота

- Пять рисовальщиков закрывают пять культур (яблоня, груша, черешня/вишня,
  слива, смородина); на остальные семь культур каталога (персик, абрикос,
  крыжовник, малина, войлочная вишня, колоновидная яблоня, йошта) рисовальщиков
  пока нет.
- Форма плода передаёт узнаваемые ботанические черты сорта (у Аббат Фетель —
  длинная шейка, у Стенлей — швов и вытянутость), но это иллюстрация, не
  фотография: цвет кожицы, точный размер и текстуру мякоти она не показывает.
